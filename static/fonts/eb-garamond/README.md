Source: https://github.com/google/fonts/tree/main/ofl/ebgaramond

The complete EBGaramond[wght].ttf and EBGaramond-Italic[wght].ttf variable fonts were converted to WOFF2 with FontTools. All glyphs and OpenType features are preserved, including standard and discretionary ligatures, which Google's Latin webfont subsets omit. Weight range: 400–800.
