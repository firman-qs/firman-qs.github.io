Nonlinear 1D Time-Domain Electromagnetic Inversion using Adaptive Differential Evolution: Application to Volcanic-Hydrothermal System

2026

Research preprint · Publication in progress

FERRON: Mesin Inversi DEA (Differential Evolution Algorithm) Data Time Domain Electromagnetic

2026

Research dataset & HKI-registered software

A one-dimensional TDEM inversion system for estimating subsurface resistivity and layer thickness using the Improved LPSR Success History Based Adaptive Differential Evolution Algorithm. Developed in Rust and Python as a research output from RIIM Kompetisi Gelombang 8.

The dataset and software are available through RIN Dataverse, version 1, with repository identifier 20.500.12690/RIN/QGVULK. The computer program was registered as intellectual property (HKI) on 16 April 2026, under registration no. 001200219.
